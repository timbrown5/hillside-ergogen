# hillside-ergogen

A repo for porting the Hillside 46 keyboard design created by @mmccoys to Ergogen.

This is a work in progress. I hope to add additional features to the boards.

### Disclaimer

The workflow in this repository comes with no promise of support. The files generated by the workflow are not finished products and should be checked manually before sending them to the PCB lab.

### Workflow

WARNING: This is very much a work in progress!

The workflow is designed to take a keyboard directory, containing an Ergogen config.yaml, generating the files needed to produce a keyboard and .

There are lots of other examples of similar workflows on GitHub. I wanted a workflow that used pinned dependencies and, where possible, pinned offical builds of binaries and docker containers. The other examples I found either didn't pin depenencies or used community produced Dockerfiles. So I tried to produce my own.
